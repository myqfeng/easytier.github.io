# [EasyTier iOS](https://github.com/EasyTier/EasyTier-iOS)

## 简介

EasyTier 的 SwiftUI 客户端，提供友好的界面以在 iOS/macOS 设备上连接 EasyTier 网络，并使用 Network Extension 框架实现系统级 VPN 集成。

Github 开源仓库：<https://github.com/EasyTier/EasyTier-iOS>
支持平台：iOS 16+/macOS 13+
