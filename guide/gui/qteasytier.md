# QtEasyTier

## 项目简介

QtEasyTier 是一个基于 Qt 框架开发的异地组网工具，使用 EasyTier 作为后端，用于创建和管理虚拟网络连接。
它提供了直观的图形界面，帮助用户轻松配置和管理虚拟网络，实现跨网络设备的安全通信。

本项目对统信 deepin / UOS 系统进行了特殊适配，采用 DTK 原生风格 UI 界面，并且提供了轻量化托盘插件，可以在不打开主程序的情况下管理网络实例配置。在 DDE 桌面环境下，可以安装 [QtEasyTier DDE 版本](https://bbs.deepin.org/post/301275)以获得更佳的使用体验！

## 项目特点

  - 安全模式UI支持：零信任架构，E2EE、Noise 握手、凭据验证等功能提升网络安全性
  - 收藏节点管理：维护常用节点信息。
  - DDE 托盘插件：deepin/UOS 用户可在系统托盘插件中快速查看和启动网络实例。

## 平台支持

- Windows 10/11 (1809以上)
- GNU/Linux
- Mac 目前暂不支持（主要是作者没有Macbook），但欢迎大佬参与贡献

## 快速上手
详情请前往[**帮助文档**](https://qtet.cn/docs-home)

- 双击 appQtEasyTier.exe 启动应用程序
- 点击左下角下角创建网络配置
- 输入网络名称、用户名、密码等基本信息或者点击下方导入配置
- 配置高级选项（可选）
- 点击 "运行网络" 按钮即可启动网络连接
